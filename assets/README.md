# Assets Directory

This directory contains the website assets:

## Images
- `profile.jpg` - Your professional profile photo (recommended: 400x400px, high quality)
- `favicon.ico` - Website favicon (16x16px or 32x32px)

## Documents
- `cv.pdf` - Your current CV in PDF format

## JavaScript
- `theme-toggle.js` - Theme switching functionality
- `animations.js` - Advanced animations and interactions

## CSS
- `styles.css` - Main stylesheet with modern design and animations

## Setup Instructions

1. **Profile Photo**: Replace the placeholder with your professional photo
   - Recommended size: 400x400px minimum
   - Format: JPG or PNG
   - High quality, professional headshot works best

2. **CV PDF**: Upload your current CV
   - Format: PDF
   - File size: Keep under 5MB for best loading performance
   - Ensure it's accessible and screen-reader friendly

3. **Favicon**: Create or upload a favicon
   - Size: 16x16px or 32x32px
   - Format: ICO, PNG, or SVG
   - Should represent your personal brand

## File Structure
```
assets/
├── images/
│   ├── profile.jpg
│   └── favicon.ico
├── cv.pdf
├── styles.css
├── theme-toggle.js
└── animations.js
```

Make sure all files are properly linked in your `_config.yml` file.
